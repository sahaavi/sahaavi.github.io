## Preview Chapter: Neural Network Fundamentals

Neural networks are composed of layers of interconnected nodes, mimicking the structure of the human brain. The basic building block is the artificial neuron, which takes several inputs, applies weights, adds a bias term, and passes the result through an activation function.

The mathematical representation of a neuron is:

$$y = \sigma(w_1x_1 + w_2x_2 + ... + w_nx_n + b) = \sigma(\mathbf{w}^T\mathbf{x} + b)$$

Where:
- $\mathbf{x}$ is the input vector
- $\mathbf{w}$ contains the weights
- $b$ is the bias term
- $\sigma$ is the activation function

Common activation functions include:
- Sigmoid: $\sigma(z) = \frac{1}{1 + e^{-z}}$
- ReLU: $\sigma(z) = \max(0, z)$
- Tanh: $\sigma(z) = \tanh(z)$
